# Қазақ тілі әлемі

1–8-сынып оқушыларына арналған интерактивті білім беру сайты: 9 сөз табы және 4 жалғау бойынша ережелер, 65 тапсырма, 13 ойын, 130 тест сұрағы және жүктелетін жұмыс парақтары (Word, PDF).

**Авторы:** Ботакөз Сакен — Павлодар қаласының №40 жалпы білім беретін орта мектебінің қазақ тілі мен әдебиеті пәнінің мұғалімі.

🌐 Сайт: https://zhuma014.github.io/qazaq-tili/

## Әзірлеушіге

React + TypeScript + Vite. Мазмұн `src/data/topics/*.ts` файлдарында сақталады (әр тақырыпқа бір файл).

```bash
npm install
npm run dev          # жергілікті сервер
npm run validate     # мазмұн құрылымын тексеру
npm run worksheets   # жұмыс парақтарын қайта жасау (LibreOffice қажет)
npm run deploy       # GitHub Pages-ке жариялау (gh-pages тармағы)
```

Тақырып мәтінін өзгерткен соң: `npm run validate && npm run worksheets && npm run deploy`.
